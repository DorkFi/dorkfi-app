# Agent notes

## Pull requests

Open a pull request as a draft while the work is still in progress. Request a reviewer only when the pull request is actually complete.

Opening a pull request files a tracking issue on the DorkFi Development Kanban and leaves it In progress. Requesting a reviewer, or assigning someone, moves that ticket to In review. The workflow adds `Closes #<issue>` to the pull request body so the ticket closes once the pull request reaches `next`.
